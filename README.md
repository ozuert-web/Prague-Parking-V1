# Prague Parking V1

## Projektbeskrivning
Detta är ett parkeringsprogram utvecklat i C# med Visual Studio.

Programmet simulerar en parkeringsplats där användaren kan hantera olika fordon via en meny i konsolen.

## Funktioner
- Parkera ett fordon
- Söka efter ett parkerat fordon
- Hämta ut ett fordon
- Flytta ett fordon till en annan parkeringsplats
- Avsluta programmet

## Teknik
- Programmeringsspråk: C#
- Utvecklingsmiljö: Visual Studio
- Plattform: .NET 10

## Hur programmet används
1. Starta programmet.
2. Välj ett alternativ i menyn.
3. Följ instruktionerna i konsolen.
4. Välj 0 för att avsluta programmet.

## Syfte
Syftet med projektet är att öva på programmering i C#, bland annat arrayer, loopar, villkor, metoder och användarinmatning.
